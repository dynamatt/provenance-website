Why teams are building on it

What the cloud QMS tools don't do

Open, user-accessible storage

Your DHF is Markdown and YAML in a git repo — not a row in someone else's database. Any tool, script, or AI agent you already trust can read and operate on it directly.

Local-first by default

Provenance runs as a single content-addressed binary. Render, check, and sign records on your own machine — nothing has to phone home to run.

Enforcement, not just visibility

A merge gate blocks any change that trips a configured rule — severity-scored, exit-code driven, wired straight into the CI you already run. Dependency diagrams don't stop a bad merge; this does.

Offline regulator handoff

Every DHF compiles to a self-contained, zero-dependency static website — plus PDF and Word — that a reviewer opens with no install and no network access.

Provenance is intended to help teams maintain relationships across design
inputs, risks, design outputs, and verification evidence as those entities
change through Git-reviewed work.

## A traceable change

1. Add or update an entity in the repository.
2. Link it to related requirements, risks, design entities, or verification
   evidence using the project's schema.
3. Review and merge the repository change through the team's established
   controls.
4. Use the resulting entity graph to inspect traceability and identify gaps.

This is a conceptual workflow, not an approved procedure. Exact commands,
checks, and supported entity formats will be documented as the product
implementation matures and validated workflows become available.
